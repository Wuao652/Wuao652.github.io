# Personal Website

This is the source code to Wuao Liu's public academic website: [https://Wuao652.github.io](https://Wuao652.github.io). Built with [Jekyll](https://jekyllrb.com/) and served by GitHub Pages.

Academic service entries live in `_data/services.yml`. Add teaching roles under
`teaching`, with a `role` and a `courses` list. Each course has a `name`, an
optional `term` (for example, `Fall 2026`), and an optional `url`.
Add service roles under `reviewing`, with a `type` and a `venues` list (one
conference or journal per item). The Service & Teaching section aligns roles
and entries on desktop and stacks them on mobile.
